# Agent maker

**When no agent fits, ordin makes one with you, in plain words.**

Category: [Agents](README.md#agents) · Status: Designed

## What you get

- A draft agent, built one question at a time.
- Reuse of parts of existing agents where they fit, and a note when other people asked for something similar.
- A rehearsal against test situations, with a result such as "4 of 5 situations passed".

## How it works

1. The agent maker drafts the agent with you.
2. ordin writes the files, checks them with fixed rules and rehearses the agent.
3. You try it on your own before anyone else sees it.
4. You publish it as a pull request, and the merge on GitHub is the publication.

## You stay in charge

- A reviewing model's opinion is shown, but it never passes or fails anything.
- You follow the review from the draft, and answer requested changes with the agent maker's help.

## Good to know

- No business user sees a file, a version or a technical choice.
