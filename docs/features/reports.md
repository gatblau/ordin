# Reports and dashboards

**Agents show data as tables, charts and key figures, and every number shows where it came from.**

Category: [Automation](README.md#automation) · Status: Designed

## What you get

- Tables, charts and key figures drawn by ordin's own code from the data agents send.
- A source for every number.
- A report kept as a dashboard and refreshed when you ask.
- Save a report as a spreadsheet, PDF, slides or document.

## How it works

1. Ask a question about your data.
2. An agent gathers the data and ordin draws the report.
3. Keep it, refresh it or save it as a file.
