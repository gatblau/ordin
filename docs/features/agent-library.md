# Agent library

**Find and add ready-made agents from agent repositories in Git, in one click.**

Category: [Agents](README.md#agents) · Status: Designed

## What you get

- Browse and search agents across every agent repository your company names or you add.
- See which repository each agent comes from.
- See what any agent is made of: its parts grouped by kind, in plain words, each one readable.
- Agents built for coding tools work here too, with no rewrite.

## How it works

1. Ordin looks in your library for an agent that fits a request.
2. If one fits, you add it with **Add it**.
3. If none fits, Ordin says what the library covers and offers the [agent maker](agent-maker.md).

## You stay in charge

- Updates that don't change what an agent may do arrive between runs. Anything else asks you first.
- When an agent starts, ordin lists anything it won't carry across or enforce. Nothing is dropped silently.

## Good to know

- ordin reads agents in its own format and in the APM format.
- People who code also see versions, the lock file and the installed files.
