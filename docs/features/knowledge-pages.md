# Knowledge pages

**Each workspace keeps pages of explanations, with their sources, written by Ordin when work finishes.**

Category: [Context](README.md#context) · Status: Designed

## What you get

- Explanations that show where each point came from.
- A mark on a page when one of its sources has changed.
- Every agent in the workspace reads the pages, so they start from what is already known.
- Pages that link to each other. Each page shows the pages it links to and the pages that link to it.
- Other names and tags on a page, and search that filters by tag, author and state.
- When Ordin recalls a fact from a page, it names the section it came from.

## How it works

1. When work finishes, Ordin writes or updates a page.
2. You can read and edit pages yourself, with the same toolbar as Markdown documents.
3. Link pages with `[[Page title]]` or `[[Page title#Heading]]`. A link to a page that doesn't exist yet starts working once the page is created.
4. Open the workspace's knowledge folder in another Markdown app, such as Obsidian, and edit it there. A file you add becomes a page, and a page you rename or move stays the same page.

## You stay in charge

- Pages are kept on your computer unless you share them through [team knowledge](team-knowledge.md).
- Ordin suggests links and points out pages that look like the same subject. Nothing changes until you accept.
- Renaming a page updates the links to it, each as a new version you can undo.
- A page deleted in another app can be brought back with **Undo**.
