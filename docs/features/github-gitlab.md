# GitHub and GitLab

**Git repositories are where documents, code, workflows, agents and team knowledge are shared.**

Category: [Documents](README.md#documents) · Status: Designed

## What you get

- Markdown documents kept in a repository, linked into a workspace and edited as formatted pages.
- Code repositories that appear in the workspace tree. See [Code workspace](code-workspace.md).
- Shared places for [workflows](workflows.md), [handovers](handovers.md) and [team knowledge](team-knowledge.md).
- [Agent repositories](agent-repositories.md), where agents are published and reviewed.

## How it works

1. Ask Ordin to add a repository from GitHub or GitLab.
2. ordin signs you in and keeps a copy on your computer.
3. Agents change documents there, and changes go back after you approve them.

## You stay in charge

- Every change to a repository waits for your approval.
- You never need to know Git. ordin does the Git steps.
