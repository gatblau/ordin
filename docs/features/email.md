# Email

**Agents read, file and draft your email. Nothing is sent until you approve the exact message.**

Category: [Messaging](README.md#messaging) · Status: Designed

## What you get

- Agents read the mail a workspace links, save attachments and draft replies.
- You can edit a draft yourself, with the same toolbar as Markdown documents.
- Recipients outside your company are marked.

## How it works

1. Link a mailbox to a workspace.
2. Ordin and the agents you allow read it and draft replies.
3. You approve each message before it is sent.

## You stay in charge

- Every message waits for your approval, exactly as it will be sent.

## Good to know

- Your company's own mail server comes first, then Microsoft 365, then Google Workspace.
