# Markdown documents

**Markdown reads as a formatted page, and can be the original of copies published elsewhere.**

Category: [Documents](README.md#documents) · Status: Designed

## What you get

- Markdown opens as a formatted page. You edit it with a toolbar for headings, bold, italic and lists, and never see Markdown symbols.
- People who code can also edit the Markdown text itself.
- Publish one original as a Confluence page, or as a Word document, PDF or slides in SharePoint.

## How it works

1. Keep the original in a Git repository.
2. Publish it to one or more places.
3. When a change to the original is merged, every copy kept up to date follows it.

## You stay in charge

- Each copy says where its original is.
- When someone edits a copy, the change comes back to you as a suggestion you can bring in or leave.
- Nothing at a destination is overwritten or deleted without your choice.
