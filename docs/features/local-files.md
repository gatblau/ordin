# Local files and folders

**Work with the files on your computer, by name, not by path.**

Category: [Documents](README.md#documents) · Status: Designed

## What you get

- Named places such as Documents, Desktop or a project folder you chose.
- Add a folder with your system's own folder picker, and drag files in and out.
- Every file shows its versions and where it came from: which run or which person.

## How it works

1. Add a folder to a [workspace](workspaces.md).
2. Give a file to an agent, open it in its own app, or save a copy elsewhere.

## You stay in charge

- Agents reach only the places you gave them.
- Removing a file moves it to the system bin.
